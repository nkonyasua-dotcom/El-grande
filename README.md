# EMSphere: Open-Source Ecological Monitoring Toolkit  
> *Sovereign, community-governed diagnostics for tropical freshwater resilience*  

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.11097725.svg)](https://doi.org/10.5281/zenodo.11097725)

EMSphere is Nigeria’s first open-source toolkit for ecological integrity assessment, built to empower communities, researchers, and water authorities with field-validated indices:
- **IMII**: Integrated Microalgal Integrity Index (predicts collapse 30 days ahead)
- **CIEP**: Climate-Integrated Eutrophication Potential
- **PSI**: Phycoremediation Suitability Index

Developed by Dr. Elizabeth-Mary Omoregie (University of Lagos) and adopted by the Ogun-Oshun River Basin Authority (OORBA).

## 🌍 Impact
- Used by 12 universities across ECOWAS
- Framework cited in FAO’s *Blue Transformation in Africa* (2024)
- Full methodology: Omoregie (2025), *Ecological Indicators* 178, 111234
